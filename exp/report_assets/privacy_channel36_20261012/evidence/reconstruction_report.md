# MS1Mv2 单频率重建评估

64 个 CASIA epoch20 模型，共用固定的 1000 张 MS1Mv2 图片（每身份一张）。
主排名按逐图 PSNR 的均值从低到高；MAE 越低越好，ID cosine 越高越好。ID 是身份特征相似度，不是识别准确率。
每个频率位置包含 Y/Cb/Cr 三个输入分量。结果衡量已训练模型的跨数据集表现，不能单独归因为频率信息量。
CASIA 与 MS1Mv2 身份重叠未审计；这是固定1000张抽样结果，不代表全量数据。
